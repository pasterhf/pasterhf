2.2.1 Спрос и эластичность

Групповой спрос Qg — сумма анкет.

Рыночный спрос:

Qd = Qg · (N / n) · k / t

Подстановка даёт 1,278; 2,52; 4,05 млн ед.

Линейный спрос строят по двум точкам, Pmax и Pф, без Pmin:

Qd = a − b·P

Система по точкам (5; 1,278) и (2,50; 2,52):

a = 3,762 млн ед./месяц

b = 0,4968 млн ед./руб.

Смысл b: минус 1 руб. цены даёт плюс 496,8 тыс. ед. спроса.

Линейная модель на Pmin = 1,25 даёт 3,141, анкета даёт 4,05. Разрыв 0,909, потому что нижнюю точку в функцию не брали. На графике линия ломаная: ниже 2,50 спрос растёт быстрее.

Цена из спроса: P = a/b − (1/b)·Q = 7,5725 − 2,0129·Q.

Шаг шкалы из 9 строк: S = a / 8 = 0,47025. В тексте работы n = 9, S = (a − 0) / (n − 1).

Выручка TR = P·Q.

Дуговая эластичность EdD = (%ΔQ) / (%ΔP).

Точечная EdT = b · P / Q. На шкале: 7,00; 3,00; 1,67; 1,00; 0,60; 0,33; 0,14; 0.

Единичная эластичность: Q = a/2 = 1,881, P = (a/b)/2 = 3,79, TR max = 7,12.

Правило выручки:

  • Ed > 1 (цена выше 3,79): снижение цены растит выручку.
  • Ed = 1: выручка максимальна.
  • Ed < 1 (цена ниже 3,79): снижение цены режет выручку, повышать цену выгодно.

Рост спроса на g % умножает и a, и b на (1 + g/100). Предельная цена a/b не меняется, оптимальная цена выручки остаётся 3,79. Максимальная выручка: 7,12 → 7,83 → 8,55 → 9,26 → 9,97 при росте 0, 10, 20, 30, 40 %. На каждые 10 % спроса плюс 0,71 млн руб. выручки.

2.2.2 Монополист

Весь рыночный спрос обслуживает одна фирма.

TVC = 1,65·Q, TC = TVC + 2,56, прибыль П = TR − TC, покрытие ВП = TR − TVC.

Шкала из 10 строк, шаг S = 3,762 / 9 = 0,418. Лучшая строка шага: прибыль 1,71 при Q = 1,672 и P = 4,21. Это ещё не оптимум.

Предельный доход падает вдвое быстрее цены:

MR = a/b − 2·(1/b)·Q = 7,5725 − 4,0258·Q

MC = AVC = 1,65, потому что AVC постоянны.

Qopt = (a/b − AVC) / (2/b) = (7,5725 − 1,65) / 4,0258 = 1,471

Popt = (a/b + AVC) / 2 = (7,5725 + 1,65) / 2 = 4,61

Левее точки MR > MC, дополнительная единица увеличивает прибыль. Правее — уменьшает.

Рост цен материалов. Нематериальная часть AVC не меняется: 1,65 − 1,0725 = 0,5775.

AVC = 1,0725·(1 + %/100) + 0,5775

Запомнить на защиту

Шесть шагов задачи: постановка, формализация, алгоритм, реализация, тест, анализ.

Пять свойств алгоритма: дискретность, определённость, результативность, массовость, понятность.

Три структуры: следование, ветвление, цикл. В Excel ветвление — ЕСЛИ, цикл по строкам — копирование формулы вниз.

ГОСТ: у процесса один вход и один выход; у ромба выходы «да» и «нет»; линии не пересекают символы; чтение сверху вниз.

Формула начинается со знака «=». Аргументы в русской версии разделяет точка с запятой.

Приоритет без скобок: ссылки, унарный минус, процент, степень, умножение и деление, плюс и минус, сцепка &, сравнения. =100+18% равно 100,18, надбавка пишется =100*(1+18%). =2*3^2 равно 18.

ЕСЛИ: =ЕСЛИ(условие; если истина; если ложь). Вложение до 64 уровней.

Оценки пособия: =ЕСЛИ(D2<79;"C";ЕСЛИ(D2<89;"B";"A")). 70 → C, 79 и 85 → B, 89 и 92 → A.

g(x) варианта 16, a = 1, b = 2, отрезок от −3 до 1, шаг 0,1.

При x ≤ 0: g = 3·SIN(x) − a·COS(x)^2. При x = 0 получается −1.

При x > 0: g = a·КОРЕНЬ(1 + b·x^2). При x = 0,1 получается √1,02 ≈ 1,01.

И(x≥−3; x≤1) на отрезке — ИСТИНА. ИЛИ(x≤0; x>1) при x = 0,1 — ЛОЖЬ.

Мастер функций: кнопка fx, вкладка «Формулы» или Shift+F3. Вложение: курсор в аргумент, поле «Имя» → «Другие функции».

Оглавление — поле TOC \o "1-3" \h \z \u. Стили «Заголовок 1/2/3». Полужирный абзац без стиля в содержание не входит. Обновление: правка заголовков — обновить поле целиком; сдвинулись только страницы — обновить номера. Код поля: Shift+F9.

1.1 Windows

Объект — то, над чем действуют: стол, окно, файл, папка, ярлык, меню.

Элемент управления принимает значение или команду. Средство управления — мышь, клавиатура или команда интерфейса.

С Windows 7 команды на модульной ленте, по вкладкам и группам. Меню «Файл» открывает Backstage.

Три вида окон: программа, документ, диалог. Модальный диалог блокирует приложение, пока его не закроют. Немодальный оставляет документ доступным.

Переключатель — ровно один выбор в группе (книжная или альбомная). Флажок независим. Поле со списком хранит текущее значение и полный набор. Список показывает набор сразу. Счётчик меняет число шагом, шкала — непрерывно.

Файл — поименованная область, имя до 255 символов, запрещены / \ : | * ? < >. Папка — каталог. Ярлык LNK около 1 Кбайт — указатель, не копия.

Макросы: DOCX и DOTX не хранят, DOCM и DOTM хранят. Excel: XLSX/XLTX без макросов, XLSM/XLTM с макросами.

Поиск: * любое число символов, ? ровно один.

Буфер: выделить, Ctrl+C или Ctrl+X, Ctrl+V. Print Screen — весь экран, Alt+Print Screen — активное окно.

Клавиатура диалога, которую нужно уметь назвать: Tab по элементам, стрелки внутри группы переключателей, пробел ставит флажок, Enter подтверждает, Esc закрывает.

1.2 Алгоритм и ГОСТ 19.701-90

Алгоритм — точное предписание порядка преобразования данных в результат.

Дискретность: шаги, следующий после предыдущего. Определённость: шаг читается одним способом, «взять подходящую функцию» алгоритмом не является. Результативность: конечный результат или обоснованный отказ, цикл без выхода противоречит. Массовость: класс задач; в Excel меняют исходные ячейки, формулы оставляют. Понятность: команды исполнителя, функции листа, а не пересказ.

Цикл с предусловием проверяет условие до тела. Цикл с постусловием — после. На блок-схеме задачи ромб «Результат верен?» и ветвь «нет» назад к реализации — это цикл с постусловием.

Символы, которые спрашивают: терминатор (начало/конец, скруглённый), процесс (прямоугольник), решение (ромб), данные (параллелограмм), предопределённый процесс (прямоугольник с двойными боками), линия со стрелкой.

1.4 Формулы

Формула = операнды + операторы, первый символ «=». Пример: =СУММ(B1:B10)/10. Имя и скобки обязательны даже без аргументов: ПИ(), СЕГОДНЯ().

Четыре операнда: константа, ссылка, функция, массив. Константу ставки и срока в расчётной формуле не держат, их выносят в ячейки.

Относительная ссылка при копировании смещается. Абсолютная $D$1 не смещается. Смешанная $D1 или D$1 фиксирует один край. Имя диапазона не равно буквам R или C и не содержит пробела.

Формулу массива завершают Ctrl+Shift+Enter, Excel ставит фигурные скобки: {=ТРАНСП(B16:E18)}.

Адресные операторы: двоеточие — диапазон, пробел — пересечение, точка с запятой — объединение. Пустое пересечение даёт #ПУСТО!. Два оператора подряд запрещены, кроме унарного минуса и процента: =-A1*18% верна.

Ошибки. Синтаксическая ломает запись: скобки, два оператора, неизвестное имя. Семантическая записана верно, но считает не то: не тот оператор, ссылка уехала, в ячейке текст.

Коды, которые нужно назвать:

  • #ДЕЛ/0! — деление на ноль или на пустую ячейку.
  • #ЗНАЧ! — неверный тип, чаще текст вместо числа.
  • #ССЫЛКА! — ссылка на удалённые ячейки.
  • #ИМЯ? — Excel не узнал имя функции или диапазона, часто кириллическая «А» вместо латинской.
  • #ЧИСЛО! — недопустимое число, например корень из отрицательного.
  • #Н/Д — нет соответствия при поиске. Это ответ «не найдено», не сбой листа. ЕСЛИОШИБКА ставят только после проверки условия.
  • #ПУСТО! — пустое пересечение диапазонов.

Пять правил против синтаксиса: функция через «Вставку функции»; диапазон мышью; скобки проверить самим; имя набирать строчными — верное Excel переводит в прописные, строчное осталось — будет #ИМЯ?; на исходные ячейки «Проверка данных» (ставка от 0 до 1, срок — целое больше нуля).

Искать ошибку: вкладка «Формулы», «Зависимости формул», «Проверка ошибок» и стрелки влияющих ячеек. Зелёный треугольник — фоновый контроль с вкладки «Формулы» в параметрах, это не отдельный тип ошибки.

1.5 Диаграммы

Таблица прямоугольная, с заголовками. Число строк не должно равняться числу столбцов, иначе Excel путает подписи и ряд. Исключение — таблица функции: первый столбец аргумент, соседние — ряды.

Тип по задаче, не по красоте:

  • гистограмма — сравнение величин по категориям;
  • график — ход показателя, категории через равные промежутки;
  • линейчатая — те же сравнения, категории по вертикали;
  • круговая — доли одного целого;
  • точечная — y от x, когда шаг X неравный и нужен масштаб оси;
  • лепестковая — несколько шкал у одной точки;
  • пузырьковая — три числа на точку.

Пузырьковая — разновидность точечной. Ось X — первая величина, ось Y — вторая, диаметр — третья. В пособии: доля рынка от численности и оборота. Четвёртый столбец с названием в ряд не входит, он только подпись. Обе оси — оси значений, оси категорий нет. Формат плоский: объём не кодирует четвёртую величину и зрительно увеличивает ближний пузырёк. Если в источнике не задать размер, получится точечная и третья переменная пропадёт.

Элементы, которые называют по рисунку: название, легенда, подписи данных, оси и их названия, основные линии сетки, область построения, область диаграммы.

Запомнить на защиту

Тождество открытой экономики: Y = C + I + G + NX, и из него S − I = NX.

Поглощение A = C + I + G, тогда NX = Y − A. Страна с дефицитом тратит больше, чем производит.

Малая открытая экономика не задаёт мировую цену и мировую ставку. Мультипликатор 1 / (1 − b + m) меньше закрытого 1 / (1 − b).

Невозможная троица: нельзя одновременно иметь фиксированный курс, свободный капитал и независимую денежную политику. Удерживаются любые две.

При плавающем курсе монетарная политика сильна, фискальная частично вытесняется через ставку и курс. При фиксации наоборот.

1.1 Платёжный баланс

Счёт текущих операций: товары, услуги, первичные доходы (труд и капитал), вторичные доходы (трансферты, в том числе пошлины ЕАЭС). Счёт капитала у Беларуси обычно невелик. Финансовый счёт показывает, чем профинансирован итог: прямые инвестиции, портфель, кредиты, торговые кредиты, резервы.

Дефицит текущего счёта значит, что резиденты потратили больше, чем заработали на внешнем контуре. Его закрывает чистое заимствование. Дефицит, закрытый прямыми инвестициями в оборудование, и дефицит, закрытый резервами или коротким долгом, оставляют разную нагрузку.

2024 год, разложение минуса 1,9 млрд долл.: товары около −4,7; услуги около +3,4 (экспорт услуг подошёл к 10 млрд, товарный минус не перекрыт); товары и услуги вместе около −1,3 млрд, или 1,7 % ВВП; первичные доходы около −1,8; вторичные около +1,2 (партнёрам ЕАЭС около 0,8, получено около 2,2). Товарно-услужный баланс — это NX в кресте. Минус по первичным доходам — плата за уже накопленный долг. Плюс по пошлинам от курса и выпуска зависит слабо.

Реальный эффективный курс рубля к корзине в 2024 году снизился на 0,82 %. Ослабление реальной цены отечественных товаров поддерживает экспорт. Резервы без переоценки почти не изменились: операционное снижение 79,1 млн долл. Дефицит года закрыт не проеданием резервов, а другими статьями финансового счёта.

Три связи дальше по тексту: NX входит в совокупный спрос и сдвигает AD; ставка и курс решают, останется ли сдвиг внутри или уйдёт в импорт и отток капитала; платёжный баланс — тождество, которое модель обязана выполнить.

1.2 Внутреннее и внешнее равновесие

Внутреннее: фактический выпуск близок к потенциальному, инфляция в коридоре. Внешнее: текущий счёт и его финансирование не требуют постоянного проедания резервов и такого долга, который сам ломает курс и ставку. Стимул занятости увеличивает импорт.

Крест открытой экономики: E = C + I + G + NX, C = a + b(Y − T), NX = X − mY. Наклон расходов b − m, не b. Равновесие по-прежнему E = Y. Отрицательный NX при этом равновесии не ошибка: S − I = NX, инвестиции больше сбережений.

Задание считает закрытый крест: рост G и I поднимает доход, рост T снижает. В открытой схеме отклик меньше, часть прироста уходит в импорт.

Две цели — два инструмента. Политика расходов (налоги, закупки, ставка) и политика переключения (курс) не заменяют друг друга.

Парадокс бережливости в открытой экономике: рост склонности к сбережению снижает потребление и равновесный доход, но повышает NX. Внутренний крест показывает спад, баланс — улучшение.

При мобильном капитале внутренняя ставка не может долго отличаться от мировой без движения резервов или курса. Беларусь не крайний случай: счёт капитала регулируется, часть финансирования связана с Россией, курс сглаживается. Направление то же: чем свободнее капитал, тем меньше своя ставка автономна.

1.3 Плавающий и фиксированный курс

Плавающий. Стимулирующая монетарная политика увеличивает деньги, снижает ставку, сдвигает LM вправо, ослабляет рубль, NX растёт, спрос получает вторую добавку. Фискальная слабее: рост G поднимает ставку, привлекает капитал, укрепляет рубль и вытесняет NX.

Фиксированный. Денежная база эндогенна. Своё увеличение денег создаёт спрос на валюту, банк продаёт резервы и забирает ликвидность обратно. Монетарная политика теряет автономность. Фискальная доходит: рост G повышает ставку, приток капитала давит курс к потолку фиксации, банк выкупает валюту, денежная масса растёт сама, LM едет вслед за IS.

Стерилизация при фиксации возвращает ту ликвидность, из-за которой валюту покупали. Пока капитал подвижен, резервы тают.

Беларусь к 2011 году: курс держали, спрос и кредит не были подчинены внешней цене рубля, разрыв копился в импорте. Пересмотр курса признал, что фиксация без подчинения денежной политики уже не исполнялась. После 2015 года цели по уровню рубля нет. Интервенция сглаживает, не обещает вчерашний курс. 1.4 Белорусская модель

Официальная формула: социально ориентированная рыночная экономика. Рынок распределяет основную массу ресурсов, государство держит занятость, базовые услуги и крупный контур: энергетика, нефтепереработка, химия, машиностроение, банки с госучастием.

1990-е: спад, высокая инфляция, несколько валютных режимов, к концу десятилетия выбор в пользу сильного государственного контура. 2000-е: рост на российском спросе, дешёвой энергии и директивном кредите при удерживаемом курсе. Внутреннее равновесие покупалось внешним. 2011: фиксация не пережила разрыв. Деноминация — 2016. С 2015 денежная политика сместилась к контролю предложения денег и инфляции, курс без цели по уровню. Прогнозные параметры по ВВП, инфляции, зарплате и инвестициям остаются ориентиром правительства.

2022: ВВП −4,7 %. Затем +3,9 % в 2023 и +4 % в 2024. Первая оценка 2025: +1,3 % при плане 4,1 %. После 2022 выросла доля административных инструментов и разворот торговли на Россию и Азию, название модели и плавающий курс сохранены.

Денежный контур 2024: цель по инфляции не выше 6 %, факт 5,2 % после 5,8 % в 2023. Ставка 9,5 % весь год. Норматив резервов: 4 % по рублёвым привлечённым, по валютным поднят на 4 п. п., до 20 %. Девалютизацию толкали резервной нормой, не курсовым правилом.

Инструменты не сваливать в одно «регулирование». Ставка 9,5 % — цена рублёвой ликвидности, сдвиг вдоль LM. Норматив 4 % и 20 % режет мультипликатор выборочно по валютным пассивам. Плавающий рубль принимает шок на NX и на рублёвые цены импорта. Прогнозные параметры задают желаемую точку на IS. Прямое регулирование цен давит наблюдаемый P и может заменить открытую инфляцию дефицитом или давлением на импорт.

Вывод главы: инфляция уложилась в цель, ставка не двигалась, курс не фиксировался, внешний счёт остался дефицитным, темп выпуска в 2025 ниже плана. Внутренний ориентир упирается во внешний баланс.

2.1 Счета. Как считать и что сказать

Выпуск = реализация + экспорт + изменение запасов = 10 185 + 970 + (−905) = 10 250.

Промежуточное потребление = материальные затраты + импорт = 5 210 + 2 130 = 7 340.

ВВП производственный = 10 250 − 7 340 = 2 910. Это сальдо счёта производства.

ВВП доходный = зарплата + соцстрах + прочие отчисления + амортизация + предпринимательский доход + косвенные налоги − субсидии = 1 090 + 390 + 40 + 810 + 560 + 290 − 410 = 2 770.

Расхождение производство − доходы = 140. Его ставят отдельной строкой, чтобы счета сошлись, и не разносят по другим статьям.

ЧВП = ВВП − амортизация = 2 910 − 810 = 2 100.

Национальный доход = ЧВП − косвенные налоги + субсидии = 2 100 − 290 + 410 = 2 220. Это сальдо счёта образования.

Личный доход = НД − расхождение − прямые налоги − соцстрах − прочие отчисления + социальные выплаты = 2 220 − 140 − 510 − 390 − 40 + 290 = 1 430.

Статистика. Экзамен и курсовая

Экзамен: вопросы ст. преподавателя Н. В. Зеленковской, кафедра «Инженерная экономика», 2025. Ответы сжаты по конспектам тем 2–11. Курсовая: МСП Беларуси, 2018–2025, файл Курсовая_Статистика_МСП_v0.29.docx, расчёт v0.14. В конце — числа, которые спрашивают по своей работе.

Обозначения в формулах: x — значение признака, f — частота, n или N — число единиц, черта сверху — средняя.

Наблюдение

Статистическое наблюдение — массовый, планомерный, научно организованный сбор сведений: у каждой единицы совокупности регистрируют отобранные признаки. Свойства статистической информации: массовость и то, что она устаревает.

Этапы: подготовка; массовый сбор; подготовка к обработке (логический и арифметический контроль); предложения по улучшению наблюдения.

Программно-методологические вопросы: цель, объект, единица наблюдения, программа признаков, формуляр, инструкция, критический момент.

Цель — достоверная информация, чтобы увидеть закономерность. Объект — совокупность, в которой идёт явление (люди, дома, организации). Единица наблюдения — носитель признаков. Отчётная единица — тот, от кого приходят данные. Они могут совпадать.

Программа — перечень существенных, точных, однозначных вопросов плюс контрольные вопросы. Формуляр индивидуальный (одна единица) или списочный (несколько). Инструкция задаёт порядок заполнения.

Объективное время — дата или период, к которому относятся данные (выпуск за месяц, фонд на дату). Субъективное время — срок, в течение которого наблюдение проводят (отчёт сдают с 1 по 5 февраля).

Формы: статистическая отчётность, специально организованное наблюдение, регистр.

По времени: текущее (непрерывное); прерывное — периодическое и единовременное.

По охвату: сплошное и несплошное (выборочное, основного массива, монографическое).

Способы: непосредственное, документальное, опрос (экспедиционный, саморегистрация, корреспондентский, анкета, явочный).

Ошибки регистрации: случайные и систематические, у респондента и у регистратора. Ошибки репрезентативности бывают только у несплошного наблюдения. Контроль: синтаксический, логический, арифметический. Счётный контроль ловит арифметику, логический — несовместимые ответы.

Сводка и группировка

Сводка — второй этап. Простая сводка считает общие итоги. Сложная добавляет группировку, итоги по группам и таблицу. По организации: централизованная, децентрализованная; по технике: ручная и механизированная.

Группировка делит совокупность на однородные группы по существенному признаку. Простая — по одному признаку, комбинационная — по нескольким сразу (возраст, стаж, профессия).

Типологическая делит качественно разнородную совокупность (формы собственности). Структурная показывает строение однородной (город и село). Аналитическая ищет связь: в основание кладут факторный признак, по группам считают среднее результативного.

Ряд распределения — упорядоченное размещение единиц по группировочному признаку. Атрибутивный ряд — по качественному признаку. Вариационный — по количественному: дискретный или интервальный.

Число групп по Стерджессу: n = 1 + 3,322·lg N. Равный интервал h = (xmax − xmin) / n. Границы записывают так, чтобы единица не попала в две группы.

Вторичная группировка пересобирает уже сгруппированные данные. Два способа: укрупнение интервалов и долевая перегруппировка (берут нужную долю частоты исходного интервала). В лекции второй способ показан на группах 50 %, 30 % и 20 %.

Абсолютная плотность ha = f / h. Относительная hω = w / h, где w = f / Σf — частость. При неравных интервалах высоту столбца гистограммы берут по плотности, не по частоте. Иначе широкий интервал выглядит «больше» только из-за ширины.

Таблицы и графики

Таблица: подлежащее (кого характеризуют, обычно строки) и сказуемое (показатели, обычно графы).

По подлежащему: простая (перечень или монография), групповая (одна группировка), комбинационная (несколько признаков в подлежащем).

По сказуемому: простая разработка (итог суммированием) и сложная (показатель делится на подгруппы). По времени: статическая на момент и динамическая за ряд периодов.

Правила: заголовок отвечает «что, где, когда»; единицы указаны; графы подлежащего — буквами, графы сказуемого — цифрами; нет пустых клеток (нет сведения — «…», нет явления — «–», ноль — 0); итоги согласованы; округление одинаковое. Анализ формальный (полнота, арифметика) и содержательный (группы и показатели).

График: поле, графический образ, масштабные ориентиры, экспликация (название, подписи, легенда).

По форме образа: диаграммы и статистические карты. Диаграммы: линейные, столбиковые, полосовые, квадратные, круговые, секторные, фигурные, знак Варзара. Ряд распределения: полигон (дискретный ряд), гистограмма (интервальный), кумулята (накопленные частоты), огива (если поменять оси кумуляты).

Картограмма красит или штрихует регион по величине признака: фоновая (густота цвета) и точечная (точка заданного масштаба). Картодиаграмма ставит диаграмму на карту.

Абсолютные и относительные величины

Показатель-категория описывает сущность без места и времени. Конкретный показатель привязан к месту и времени. Индивидуальный — одна единица, сводный — группа или вся совокупность. Моментный — на дату, интервальный — за период.

Абсолютные — первичная форма, именованные. Натуральные (кг, м), условно-натуральные (через коэффициент: параметр изделия / параметр базы; в лекции тракторы сведены к МТЗ-50, итог 478,4 усл. шт.), стоимостные, трудовые (человеко-час), комбинированные (кВт·ч).

Относительная величина — отношение двух абсолютных. Формы: коэффициент, процент, промилле (‰, на 1 000), продецимилле.

Виды:

  • планового задания: план / факт базы;
  • выполнения плана: факт / план;
  • динамики: отчёт / база, или ОВПЗ · ОВВП;
  • структуры: часть / целое;
  • координации: часть / другая часть, принятая за базу;
  • сравнения: один объект / другой объект в том же времени;
  • интенсивности: разноименные величины (плотность населения, выработка).

Цепные и базисные темпы: произведение цепных коэффициентов динамики равно базисному.

Средние

Средняя — типичный уровень признака на одну единицу. Случайные отклонения погашаются, остаётся то, что дано основными факторами. Считать среднюю по неоднородной совокупности нельзя: сначала группировка.

Степенные средние. Общий вид: корень степени k из средней k-х степеней. Чем выше k, тем больше средняя (правило мажорантности): гармоническая ≤ геометрическая ≤ арифметическая ≤ квадратическая ≤ кубическая.

Арифметическая простая x̄ = Σx / n. Взвешенная x̄ = Σxf / Σf. Её берут для объёма, выработки, абсолютных уровней.

Гармоническая — когда веса даны не частотами, а произведениями x·f (известен фонд зарплаты, неизвестна численность). Взвешенная: Σw / Σ(w/x).

Геометрическая — средний коэффициент роста: корень степени n из произведения цепных коэффициентов.

Квадратическая — в показателях вариации, из неё выходит среднее квадратическое отклонение.

Структурные средние положение ряда не «усредняют арифметически».

Мода — варианта с наибольшей частотой. В дискретном ряду её видно. В интервальном:

Mo = x0 + h·(fMo − fMo−1) / [(fMo − fMo−1) + (fMo − fMo+1)]

x0 — нижняя граница модального интервала, h — его ширина. Если модальный интервал первый, частота предыдущего равна 0.

Медиана — середина ранжированного ряда. Номер в несгруппированном ряду: (n+1)/2 при нечётном n; при чётном — среднее двух центральных. В дискретном вариационном ряду идут по накопленным частотам до первой, которая не меньше N/2. В интервальном:

Me = x0 + h·(0,5·N − SMe−1) / fMe

SMe−1 — накопленная частота до медианного интервала.

Если Mo < Me < x̄, распределение скошено вправо: длинный хвост больших значений тянет среднюю. Если наоборот — влево.

Вариация

Вариация — различие значений признака внутри совокупности. Среднюю без вариации читать опасно: одна и та же средняя бывает у кучного и у разбросанного ряда.

Абсолютные, в единицах признака:

  • размах R = xmax − xmin, смотрит только на края;
  • среднее линейное отклонение d = Σ|x − x̄| / n, для взвешенного в знаменателе Σf;
  • дисперсия σ² = Σ(x − x̄)² / n, взвешенная Σ(x − x̄)²f / Σf;
  • среднее квадратическое отклонение σ = √σ².

Относительные, чтобы сравнить разные признаки:

  • коэффициент осцилляции VR = R / x̄ · 100 %;
  • линейный коэффициент Vd = d / x̄ · 100 %;
  • коэффициент вариации Vσ = σ / x̄ · 100 %.

По лекции совокупность однородна, если Vσ не выше примерно 30–35 %. В курсовой порог назван 30 %. Выше — дробить совокупность.

Свойства дисперсии:

  1. Дисперсия постоянной равна нулю.
  2. Сдвиг всех значений на A дисперсию не меняет.
  3. Умножение всех значений на C умножает дисперсию на C².
  4. Дисперсия относительно любой другой величины B больше дисперсии относительно средней: σ²(B) = σ² + (x̄ − B)². Минимум дисперсии — от средней.

Правило сложения: общая = внутригрупповая средняя + межгрупповая. Межгрупповая — разброс групповых средних вокруг общей, это систематическая вариация от фактора группировки. Внутригрупповая — разброс внутри групп, остаточная. Эмпирический коэффициент детерминации: межгрупповая / общая. Эмпирическое корреляционное отношение — корень из него.

В нормальном распределении около 68,3 % наблюдений лежит в x̄ ± σ, 95,4 % в x̄ ± 2σ, 99,7 % в x̄ ± 3σ.

Связь

Функциональная связь: каждому x отвечает одно y. Корреляционная: при одном x значения y рассеяны, видна тенденция. Прямая и обратная; линейная и криволинейная.

Количественные признаки. Поле корреляции. Линейный коэффициент Пирсона r от −1 до 1. Знак — направление, модуль — теснота: до 0,3 слабая, 0,3–0,7 умеренная, выше 0,7 тесная (ориентир лекций; на экзамене назвать шкалу, которой пользуется кафедра, если она дана в задачнике). Линейное уравнение yx = a + bx, параметры — метод наименьших квадратов. b показывает, на сколько в среднем меняется y при росте x на единицу.

Ранговая корреляция, когда значения заменяют рангами или признак порядковый. Коэффициент Спирмена:

ρ = 1 − 6·Σd² / [n(n² − 1)]

d — разность рангов одного объекта по двум признакам. При связанных рангах берут средние ранги. Кендалл считает число согласованных и несогласованных пар рангов.

Качественные признаки. Четырёхклеточная таблица: a и d — согласованные клетки, b и c — несогласованные.

Коэффициент ассоциации Юла: (ad − bc) / (ad + bc). Связь считают заметной, если модуль не меньше 0,5.

Коэффициент контингенции: (ad − bc) / √[(a+b)(c+d)(a+c)(b+d)]. Он всегда не больше модуля ассоциации. Связь заметна примерно от 0,3.

Критерий хи-квадрат сравнивает эмпирические и теоретические частоты. Если расчётное значение не больше табличного при выбранной вероятности и числе степеней свободы, расхождение можно счесть случайным. В лекции этим же критерием проверяют близость распределения к нормальному.

Ряды динамики

Ряд: уровни y и время t. Моментный (на дату, складывать уровни нельзя) и интервальный (за период, складывать можно). Равные и неравные промежутки. Стационарный и с тенденцией.

Абсолютный прирост цепной Δц = yi − yi−1, базисный Δб = yi − y0. Сумма цепных равна базисному.

Темп роста цепной Трц = yi / yi−1, базисный Трб = yi / y0. Произведение цепных коэффициентов равно базисному.

Темп прироста = темп роста − 1, или Δ / уровень базы сравнения.

Абсолютное значение 1 % прироста A = Δц / Тпрц(%) = yi−1 / 100. Его нельзя складывать «проценты от разных баз».

Средний уровень интервального ряда с равными периодами — арифметическая простая. С неравными — взвешенная по длине периода. Моментный ряд с равными промежутками — средняя хронологическая: полусумма крайних плюс внутренние уровни, делённые на число промежутков (на n−1).

Средний абсолютный прирост = (yn − y0) / (n − 1). Средний коэффициент роста — геометрическая из цепных, или корень степени (n−1) из yn/y0.

Методы тенденции: укрупнение интервалов; скользящая средняя (короткий ряд сглаживают окном, концы теряются); аналитическое выравнивание, чаще прямая y = a + bt, t отсчитывают от середины, чтобы Σt = 0. Индекс сезонности: фактический уровень / выровненный, либо среднее сезона / общую среднюю.

Экстраполяция — уровень за пределами ряда, вперёд или в прошлое. Интерполяция — пропущенный уровень внутри ряда. Простые приёмы: последний уровень плюс средний прирост, умноженный на число шагов; либо последний уровень, умноженный на средний коэффициент роста в степени числа шагов. По тренду подставляют нужное t. Упреждение в лекции советуют не дальше 5 лет: условия явления меняются.

Индексы

Индекс — относительный показатель величин, которые нельзя складывать напрямую (цены разных товаров). Индивидуальный i — однородное явление, общий I — разнородное. 0 — базис, 1 — отчёт. q — количество, p — цена, z — себестоимость, t — трудоёмкость, pq — товарооборот.

Индивидуальный iq = q1/q0, так же для цены и себестоимости.

Агрегатный индекс физического объёма Ласпейреса, веса базисные: Iq = Σq1p0 / Σq0p0.

Агрегатный индекс цен Пааше, веса отчётные: Ip = Σp1q1 / Σp0q1.

Индекс товарооборота Ipq = Σp1q1 / Σp0q0.

Связь: Ipq = Ip · Iq. Разность числителя и знаменателя — абсолютный прирост в деньгах. Прирост товарооборота раскладывается на прирост за счёт цен и за счёт объёма, и эти два абсолютных прироста в сумме дают общий.

Индекс переменного состава меняет и индексируемую величину, и веса (структуру). Индекс постоянного состава фиксирует веса, обычно на отчёте, и показывает чистое изменение качественного показателя. Индекс структурных сдвигов фиксирует качественный показатель и меняет только структуру. Их произведение: переменный = постоянный · структурный.

Качественные индексы (цена, себестоимость) обычно взвешивают отчётными весами, количественные (физический объём) — базисными.

Трудоёмкость и производительность взаимообратны, их индексы тоже: индекс производительности = 1 / индекс трудоёмкости.

Среднеарифметическая форма индекса объёма: Σ i_q · q0p0 / Σ q0p0. Среднегармоническая форма индекса цен: Σ p1q1 / Σ (p1q1 / i_p).

Выборка

Выборочное наблюдение — несплошное, единицы отбирают случайно, по выборке судят о генеральной совокупности. Ошибка регистрации плюс ошибка репрезентативности.

Виды отбора: индивидуальный, групповой, комбинированный. Способы: случайный, механический (каждая k-я), типический (сначала группы, потом отбор внутри; пропорциональный берёт один процент из каждой группы, непропорциональный — поровну штук), серийный (берётся вся серия: бригада, партия), малая выборка (меньше 30 единиц), моментные наблюдения (фиксируют состояние в случайные моменты, так изучают рабочее время).

Повторный отбор возвращает единицу в совокупность, бесповторный — нет.

Символы: N и n — объёмы генеральной и выборки; x̄ и x̃ — средние; w — выборочная доля; σ² — дисперсия; для доли дисперсия w(1−w).

Средняя ошибка случайной повторной выборки μ = σ / √n. Бесповторной μ = √[σ²/n · (1 − n/N)].

Предельная ошибка Δ = t·μ. Коэффициент доверия t по лекции: 1 → 0,683; 1,5 → 0,866; 2 → 0,954; 2,5 → 0,988; 3 → 0,997; 3,5 → 0,999.

Для доли в формулу вместо σ² ставят w(1−w). Для типического отбора берут среднюю внутригрупповую дисперсию. Для серийного в формуле стоят число серий R и число отобранных серий r и межсерийная дисперсия.

Объём выборки выражают из предельной ошибки.

Повторный, для средней: n = t²σ² / Δ².

Бесповторный: n = t²σ²N / (Δ²N + t²σ²).

Для доли σ² заменяют на w(1−w). Если долю до обследования не знают, берут максимум дисперсии доли 0,25.

Пример лекции: p = 0,866, значит t = 1,5; σ = 2; Δ не больше 0,8; N = 350. Подстановка в бесповторную формулу даёт нужное n. Сначала считают повторную оценку t²σ²/Δ² = 2,25·4 / 0,64 = 14,06, затем поправку на конечную совокупность.

Распространение на генеральную совокупность: генеральная средняя лежит в x̃ ± Δ, генеральная доля в w ± Δ. Точечная оценка генерального итога — выборочная средняя, умноженная на N, с тем же коридором ошибки.
